설명 문서 시각화 레퍼토리

대상 독자: HTML/CSS/JS에 기본적인 이해가 있는 문서 작성자, JSON 데이터 블록과 스니펫을 복사·수정할 수 있는 수준.

이 파일은 열람용 레퍼토리이며 문서는 explainer-skeleton.html에서 시작한다. 실제 설명 문서를 쓸 때 필요한 시각화 형태를 여기서 찾아 복사한다.

아래 레시피의 JS는 window.EXPL(get/fmt/svgEl/wireTip/verifyNumbers/renderBarsH)이 본문 상단 공통 스크립트에서 이미 로드되어 있다고 가정하며, 레시피는 항상 EXPL.get(...)처럼 이 네임스페이스를 통해 호출한다 — 그래야 레시피만 골라 다른 문서에 복사해도 그대로 동작한다. 레시피를 복사할 때는 스니펫 첫 줄의 "필요 데이터" 주석이 명시한 필드를 문서의 임베드 데이터 블록에도 추가해야 한다.
